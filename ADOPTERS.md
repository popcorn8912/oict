# Adopters & Trials

This page lists teams and organizations that have evaluated, trialled, or integrated OICT. Each entry links to a public trial report or a written statement.

To be listed, file a [trial report](../../issues/new?template=trial-report.yml) or open a pull request adding a row. Only list your organization with its permission.

| _Your team here_ | | Evaluation · Trial · Integration · Production | 3D · AR · VR · Voice · Chat agent | | |

**Stages**

- **Evaluation** — ran the samples and conformance suite.
- **Trial** — ran the conformance suite against your own integration and recorded the results.
- **Integration** — adopted OICT rules in a service under development.
- **Production** — OICT rules enforced in a live service.
