# Code of Conduct

OICT is a technical project about protecting people — including young people — when they shop. We expect the same care in how we treat each other.

**We commit to** being welcoming to contributors of every background and experience level; giving and receiving technical criticism about ideas, not people; and assuming good faith while staying open to correction.

**We do not accept** harassment, personal attacks, discriminatory language, sexualized content, publishing someone's private information, or sustained disruption of discussions.

**Scope.** This applies in all project spaces — issues, pull requests, discussions, and events where someone represents the project.

**Reporting.** Report concerns privately to the maintainer through the contact listed in [SECURITY.md](SECURITY.md). Reports are handled confidentially. Maintainers may edit or remove contributions, and may temporarily or permanently ban participants who violate this code.

This code is informed by the Contributor Covenant, version 2.1.
