Sample clients

Two small applications that buy through the OICT reference server with real signed tokens. Both run in the browser, need no build step, and use the same 120-line client in shared/oict-client.js.

3D showroom

A three.js scene. Pick products off pedestals, build a multi-item cart, confirm exactly what you see, and watch price changes, retries and withdrawn rights get handled.

web-3d/

Chat assistant

An assistant that fills your cart under a delegated grant that can only draft. It tries to buy for you and is refused; late answers about an old cart are marked as outdated.

chat-assistant/ 
docker compose up --build
# clients:  http://localhost:8080
# server:   http://localhost:8787  (PostgreSQL behind it)
